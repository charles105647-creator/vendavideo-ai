# VendaVídeo AI — GitHub Pages

Protótipo estático mobile-first, preparado para publicar pelo navegador do celular.

## Publicar no GitHub
1. Entre em https://github.com e crie uma conta quando estiver pronto.
2. Crie um repositório público chamado `vendavideo-ai`.
3. Toque em Add file > Upload files e envie `index.html` e `README.md` (ou envie este arquivo ZIP e extraia antes, no gerenciador de arquivos).
4. Vá em Settings > Pages.
5. Em Build and deployment, selecione Deploy from a branch, branch `main`, folder `/(root)` e salve.
6. Aguarde a publicação; o endereço aparecerá na seção Pages.

## Limitações desta primeira versão
- Interface e rascunhos locais funcionam no navegador; as fotos são pré-visualizadas localmente e não são enviadas.
- Não gera áudio nem vídeo real ainda.
- Não coloque chaves de APIs em `index.html`. Para produção, conecte um backend seguro e provedores de voz/vídeo.
